        Настройки доски

        Основные настройки лежат в файле config.js на GitHub. Здесь можно переопределить их только для этого устройства. Пустая ссылка на таблицу — показываются демо-данные.

        Файл → Поделиться → Опубликовать в интернете → лист с ответами → CSV.

        1. Полная инструкция — в файле README.md в репозитории.
        2. Статусы в таблице: опубликовано, решено, отклонено. Пустой статус — на модерации.
        3. Данные обновляются раз в 30 секунд, страница перезагружается каждую ночь в 4:00 и подхватывает новый config.js.
