# Доска подъезда — запуск MVP

Экран цифровой доски объявлений для подъезда. Жители пишут через Google-форму по QR-коду, куратор модерирует сообщения в Google-таблице, а экран раз в 30 секунд забирает одобренное и показывает в виде бумажек. Нерешённые проблемы на экране со временем «стареют».

Схема работы:

```
Житель → Google-форма → таблица «Ответы» → куратор ставит статус
       → лист «Экран» (только одобренное) → опубликован как CSV
       → сайт на GitHub Pages → браузер планшета в подъезде
```

Всё бесплатно: нужны аккаунт Google, аккаунт GitHub и любой планшет или ноутбук с браузером. Первый запуск занимает около часа.

---

## Что лежит в папке

| Файл | Зачем |
|---|---|
| `index.html` | Сам экран. Трогать не нужно. |
| `config.js` | Настройки: название, ссылка на таблицу, ссылка на форму. **Это единственный файл, который вы правите.** |
| `manifest.webmanifest`, `icon-192.png`, `icon-512.png` | Чтобы экран можно было добавить на главный экран планшета и открывать без адресной строки. |
| `.nojekyll` | Служебный файл для GitHub Pages. Не удалять. |
| `README.md` | Эта инструкция. |

Пока в `config.js` нет ссылки на таблицу, экран показывает демо-данные — в шапке будет пометка «Демо-данные».

## Шаг 1. Google-форма

1. Откройте [forms.google.com](https://forms.google.com) → «Пустая форма». Назовите её, например, «Доска подъезда №3».
2. Добавьте вопросы. **Названия вопросов пишите точно так** — по ним экран находит нужные столбцы:

   | Вопрос | Тип | Варианты | Обязательный |
   |---|---|---|---|
   | `Сообщение` | Абзац | — | да |
   | `Категория` | Один из списка | Объявление, Просьба, Проблема, Идея | да |
   | `Зона` | Раскрывающийся список | Лифт, Лестница, Вход, Двор, Мусоропровод, Другое | нет |
   | `Можно показать на выставке` | Один из списка | Да, Нет | нет |

3. В вопросе «Сообщение» нажмите ⋮ → «Проверка ответов» → «Длина» → «Максимальное количество символов» → `280`.
4. В описании формы напишите правила. Например:
   > Сообщение увидят соседи на экране в подъезде. Управляющая компания его автоматически не получит. Не указывайте номера квартир, имена и телефоны других людей. Сообщения проверяет куратор, появляются на экране в течение дня.
5. Вкладка «Настройки»:
   - «Ответы» → «Собирать адреса электронной почты» → **Не собирать**.
   - «Ограничить одним ответом» — **выключено** (иначе форма потребует войти в аккаунт Google).
6. Нажмите «Отправить» → значок ссылки → «Сократить URL» → скопируйте ссылку вида `https://forms.gle/…`. Она понадобится в шаге 4.

> После запуска **не меняйте порядок и названия вопросов**: Google добавит в таблицу новые столбцы, и формулы съедут.

## Шаг 2. Таблица и модерация

1. В форме: вкладка «Ответы» → «Связать с Таблицами» → «Создать таблицу». Откроется таблица с листом **«Ответы на форму (1)»**. Столбцы A–E заполняет форма:

   | A | B | C | D | E |
   |---|---|---|---|---|
   | Отметка времени | Сообщение | Категория | Зона | Можно показать на выставке |

2. Справа от них впишите в первую строку заголовки ещё четырёх столбцов. Их заполняет куратор:

   | F | G | H | I |
   |---|---|---|---|
   | `Статус` | `Решено` | `Канал` | `Тоже` |

   - **Статус** — `опубликовано`, `решено` или `отклонено`. Пустой статус = сообщение на модерации, на экран не попадает.
   - **Решено** — дата, когда жители сообщили, что проблему устранили (например, `21.10.2026`). По ней экран считает «решено за N дней».
   - **Канал** — `бумага` для записок из ящика. Пусто = пришло через форму.
   - **Тоже** — сколько соседей сказали «у меня то же самое» (число). Заполняется вручную, если вы это собираете.

3. Сделайте выпадающий список для статуса: выделите столбец F → «Данные» → «Настроить проверку данных» → «Добавить правило» → «Раскрывающийся список» → варианты `опубликовано`, `решено`, `отклонено` → «Готово».

4. Создайте второй лист (плюсик внизу слева) и назовите его **«Экран»**. В ячейку A1 вставьте формулу:

   ```
   =QUERY('Ответы на форму (1)'!A:I; "select A, B, C, D, F, G, H, I where lower(F) = 'опубликовано' or lower(F) = 'решено'"; 1)
   ```

   На этом листе всегда будут только одобренные и решённые сообщения. **Публиковать в интернете будем только его** — неотмодерированные тексты наружу не попадут.

   - Если таблица на английском и формула выдаёт ошибку, замените `;` на `,`.
   - Если вы не добавляли вопрос про выставку, столбцы куратора будут E–H. Тогда формула такая:

     ```
     =QUERY('Ответы на форму (1)'!A:H; "select A, B, C, D, E, F, G, H where lower(E) = 'опубликовано' or lower(E) = 'решено'"; 1)
     ```

### Бумажные записки

Добавьте строку в конец листа «Ответы на форму (1)» вручную: в A — дата и время в формате `21.10.2026 18:30:00`, в B — текст записки, C и D — категория и зона, F — `опубликовано`, H — `бумага`. На экране такая записка будет нарисована на тетрадном листе с пометкой «с бумаги».

## Шаг 3. Опубликовать лист «Экран»

1. В таблице: «Файл» → «Поделиться» → «Опубликовать в интернете».
2. В первом списке выберите **лист «Экран»** (не «Весь документ»!), во втором — **«Значения, разделенные запятыми (.csv)»**.
3. Раскройте «Опубликованный контент и настройки» и проверьте, что включено «Автоматически публиковать изменения».
4. Нажмите «Опубликовать» → «ОК». Скопируйте ссылку вида:
   `https://docs.google.com/spreadsheets/d/e/2PACX-…/pub?gid=…&single=true&output=csv`
5. Проверьте: откройте ссылку в новой вкладке. Должен скачаться или открыться текст, где первая строка — заголовки столбцов.

Google обновляет опубликованный файл не мгновенно: изменения в таблице доходят до экрана за время от нескольких секунд до ~5 минут.

## Шаг 4. Сайт на GitHub Pages

### 4.1. Аккаунт и репозиторий

1. Зарегистрируйтесь на [github.com](https://github.com) (бесплатно). Имя пользователя войдёт в адрес сайта, например `daria-board`.
2. Справа вверху «+» → «New repository».
   - Repository name: `doska`
   - **Public** (на бесплатном тарифе GitHub Pages работает только для публичных репозиториев).
   - Остальное не трогать → «Create repository».

### 4.2. Загрузить файлы

1. На странице пустого репозитория нажмите ссылку **«uploading an existing file»**.
2. Распакуйте архив и перетащите в окно браузера **все файлы из папки** (не саму папку): `index.html`, `config.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `.nojekyll`, `README.md`.
   - Файл `.nojekyll` может быть скрыт. На Mac — `Cmd + Shift + .` в Finder, на Windows — «Вид» → «Скрытые элементы». Если не получается — пропустите его, сайт заработает и без него.
3. Внизу «Commit changes».

### 4.3. Включить Pages

1. В репозитории: «Settings» → слева «Pages».
2. «Source» → **Deploy from a branch**. «Branch» → **main**, папка **/(root)** → «Save».
3. Подождите 1–2 минуты и обновите страницу. Сверху появится: *Your site is live at* `https://ВАШ-ЛОГИН.github.io/doska/`. Это и есть адрес экрана.

### 4.4. Вписать свои ссылки в config.js

1. В репозитории откройте `config.js` → значок карандаша (Edit).
2. Вставьте ссылки между кавычками:

   ```js
   window.BOARD_CONFIG = {
     name: "Подъезд №3",
     csv: "https://docs.google.com/spreadsheets/d/e/2PACX-…/pub?gid=…&single=true&output=csv",
     form: "https://forms.gle/…"
   };
   ```

3. «Commit changes…» → «Commit changes». Через 1–2 минуты сайт обновится.

Кавычки и запятые в конце строк важны: если удалить запятую после ссылки, экран не загрузит настройки и покажет демо-данные.

## Шаг 5. Проверить, что всё связано

1. Откройте `https://ВАШ-ЛОГИН.github.io/doska/` на компьютере.
2. В шапке **нет** пометки «Демо-данные», внизу справа — «обновлено ЧЧ:ММ» с зелёной точкой. Справа внизу — QR-код.
3. Отсканируйте QR телефоном, отправьте тестовое сообщение.
4. В таблице поставьте ему статус `опубликовано`. Через 1–5 минут оно появится на экране.
5. Поставьте статус `решено` и дату в «Решено» — сообщение переедет в блок «Жители отметили „решено“».
6. Удалите тестовую строку.

## Шаг 6. Планшет в подъезде

### Android-планшет (самый простой вариант)

1. Откройте адрес сайта в Chrome → ⋮ → «Добавить на главный экран» (или «Установить приложение»). Значок «Доска» откроет экран без адресной строки.
2. Чтобы экран не гас: «Настройки» → «О планшете» → 7 раз нажать «Номер сборки» → появится «Для разработчиков» → включить **«Не выключать экран»** (работает, пока планшет на зарядке).
3. Чтобы прохожие не вышли из приложения: «Настройки» → «Безопасность» → **«Закрепление приложений»** включить. Открыть «Доску» → кнопка недавних приложений → значок приложения → «Закрепить».
4. Альтернатива для долгой работы — приложение-киоск (например, Fully Kiosk Browser): оно само держит экран включённым и перезапускает страницу после сбоя.

### iPad

1. Safari → адрес сайта → «Поделиться» → «На экран „Домой“».
2. «Настройки» → «Экран и яркость» → «Автоблокировка» → **Никогда**.
3. «Настройки» → «Универсальный доступ» → **«Гид-доступ»** включить. Открыть «Доску», трижды нажать верхнюю (или домашнюю) кнопку → «Начать». iPad останется на этом экране.

### Старый ноутбук или компьютер с монитором

Откройте сайт в Chrome и нажмите на экране кнопку «На весь экран» (или F11). В настройках питания отключите сон и выключение дисплея.

### Raspberry Pi с монитором (вариант для выставки)

В автозапуск добавить:
```
chromium-browser --kiosk --noerrdialogs --disable-infobars https://ВАШ-ЛОГИН.github.io/doska/
```

### Связь и питание

- Интернет: Wi-Fi соседа (с его согласия) или раздача с телефона/модема с отдельной SIM-картой. Трафик крошечный — несколько мегабайт в день.
- Питание: розетка в подъезде по согласованию с управляющей компанией. Без удлинителей по лестнице: путь эвакуации должен оставаться свободным.
- Если связь пропала, экран продолжает показывать последние данные и пишет «нет связи» внизу.

### Что экран делает сам

- Забирает данные раз в 30 секунд.
- Если сообщения не помещаются, листает страницы раз в 15 секунд.
- С 23:00 до 7:00 снижает яркость.
- Каждую ночь в 4:00 перезагружается и подхватывает изменения из `config.js`.

## Работа куратора каждый день (~10 минут)

1. Открыть таблицу, отфильтровать пустой «Статус» — это новые сообщения.
2. Каждому поставить `опубликовано` или `отклонено` по правилам:
   - нет номеров квартир, имён, телефонов других людей;
   - нет оскорблений, угроз, мата, политической агитации;
   - нет рекламы (соседские «отдам/продам» можно).
3. Забрать записки из ящика и внести их строками с каналом `бумага`.
4. Если жители сказали, что проблема устранена, — статус `решено` и дата в «Решено».
5. Сфотографировать экран и стену рядом — это архив для выставки.

Объявления, просьбы и идеи сами исчезают с экрана через 3 недели. Проблемы остаются, пока не помечены «решено».

## Если что-то не работает

| Что видно | Причина и что сделать |
|---|---|
| В шапке «Демо-данные» | В `config.js` пустая ссылка `csv` или сломан синтаксис (пропала кавычка или запятая). Проверьте файл. Если на этом устройстве когда-то сохраняли «Настройки», нажмите «Настройки» → «Сбросить к config.js». |
| Внизу красная точка «нет связи» | Нет интернета на планшете или ссылка не на CSV. Откройте ссылку `csv` в браузере: должен быть текст с запятыми, а не страница Google. |
| Экран пустой, хотя сообщения есть | У сообщений пустой статус, или в формуле QUERY не те буквы столбцов. Откройте лист «Экран» — там должны быть строки. |
| Сообщение одобрено, но не появилось | Подождите до 5 минут: Google обновляет опубликованный файл с задержкой. |
| Нет QR-кода | Пустая ссылка `form` в `config.js` или нет интернета (библиотека QR загружается из сети). |
| Шрифт на бумажках не рукописный | Нет интернета при загрузке страницы — шрифты тоже из сети. Перезагрузите страницу, когда связь появится. |
| Сайт выдаёт 404 | Pages ещё не включился (подождите 2 минуты) или файлы загружены внутри папки: `index.html` должен лежать в корне репозитория. |

## Приватность

- Репозиторий и сайт публичные: адрес экрана и ссылку на CSV может увидеть любой, кто их узнает. Поэтому публикуется **только лист «Экран»** с одобренными сообщениями, а форма не собирает имена и почту.
- Страница помечена для поисковиков как «не индексировать».
- Таблицу с ответами (лист «Ответы на форму (1)») не открывайте для общего доступа.
- После окончания пилота: «Файл» → «Поделиться» → «Опубликовать в интернете» → «Остановить публикацию», а репозиторий можно сделать приватным или удалить.
